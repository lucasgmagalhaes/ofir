WHY OFIR

Less friction.
More building.

Ofir brings a small, readable syntax to systems programming. Write code that is easy to follow, while keeping ownership, predictable performance, and native compilation in your hands.

{ }
01

Readable by design

Familiar syntax, inferred types, and no semicolons. Spend time on the problem instead of ceremony.

↗
02

Safety with control

Ownership and borrowing make memory behavior explicit, without a garbage collector.

▣
03

Built to compile

Ofir emits LLVM IR and uses clang to produce native programs. The compiler is written in Ofir.
