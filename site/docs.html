01 / SETUP

Get started

Clone the repository, then build the stage 0 compiler and runtime. You will need a C11 compiler, make, Python 3, and clang 17 or later.

TERMINAL · MACOS / LINUX
$ git clone https://github.com/lucasgmagalhaes/ofir.git
$ cd ofir
$ make

On Windows, use Git Bash, clang, and a MinGW-w64 toolchain; run mingw32-make instead of make. See the Windows setup guide for details.

02 / HELLO WORLD

Your first program

Create hello.of with a main function. String interpolation puts the value of name into the greeting.

hello.of
fn main() {
    const name = "Ofir"
    println("Hello, {name}!")
}

Run it with the compiler you just built:

TERMINAL
$ build/stage0/ofir run hello.of
Hello, Ofir!
