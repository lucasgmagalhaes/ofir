# Ofir website

A static Astro site with a landing page and getting-started guide.

Use Node.js 22.23.4 or newer. From this directory, run `npm ci` and
`npm run dev` for local development.
Run `npm run build` to generate static pages in `dist/`, then
`npm run preview` to inspect the build. Astro imports the logo from
`docs/assets/logo.png` in the repository; no copy of the source asset is
needed.

The site introduces Ofir; the [language specification](../docs/spec/README.md),
[standard library](../docs/std/README.md), and
[toolchain guide](../docs/design/toolchain.md) remain the detailed references.
