# Ofir website

A small, dependency-free landing page and getting-started guide.

Open `site/index.html` in a browser, or serve the repository root with
`python3 -m http.server 8000` and visit `http://localhost:8000/site/`.
The pages use `docs/assets/logo.png` from this repository.

The site introduces Ofir; the [language specification](../docs/spec/README.md),
[standard library](../docs/std/README.md), and
[toolchain guide](../docs/design/toolchain.md) remain the detailed references.
