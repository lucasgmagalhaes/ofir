# E0208: invalid glob import

A glob import (`import path.*`) imports every public member of a module
under its own name (spec 7.2). It cannot be re-exported with `pub`, so a
module's public members stay the ones it names, and it takes no `as`
alias. Import the module or each member instead.

## Example

```ofir
pub import std.strings.*

fn main() {
    println(join(["a", "b"], ", "))
}
```

## Fix

```ofir
pub import std.strings.join

fn main() {
    println(join(["a", "b"], ", "))
}
```
