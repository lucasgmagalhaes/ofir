# E0327: interface embeds itself

An interface embeds itself, directly or through the interfaces it embeds
(spec 9.4). Its methods would have no end.

## Example

```ofir
interface Node {
    Tree
    fn id(self) int
}

interface Tree {
    Node
}

fn main() {
}
```

## Fix

Remove one of the embeddings:

```ofir
interface Node {
    fn id(self) int
}

interface Tree {
    Node
}

fn main() {
}
```
