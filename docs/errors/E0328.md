# E0328: conflicting embedded methods

A method reaches an interface more than once, through two embedded
interfaces or one embedded interface and a declaration of its own, with
another `self` mode or signature (spec 9.4). Methods with the same
signature merge.

## Example

```ofir
interface Named {
    fn name(self) str
}

interface Numbered {
    fn name(self) int
}

interface Labeled {
    Named
    Numbered
}

fn main() {
}
```

## Fix

Give the methods the same signature, or different names:

```ofir
interface Named {
    fn name(self) str
}

interface Numbered {
    fn number(self) int
}

interface Labeled {
    Named
    Numbered
}

fn main() {
}
```
