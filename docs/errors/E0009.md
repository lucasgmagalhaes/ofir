# E0009: bidirectional control character

The characters U+202A to U+202E and U+2066 to U+2069 change the order in
which text is displayed. In source code they can make a comment or a
string look like code, or hide code inside what looks like a comment, so
that a program reads differently from how it runs ("Trojan Source").
They are an error anywhere in a source file (spec 1.1).

## Example

A comment that holds U+202E (RIGHT-TO-LEFT OVERRIDE); an editor shows
the rest of the line reversed.

```text
/* <U+202E> } if isAdmin { */
```

## Fix

Remove the character. A string that needs it writes it as an escape,
which is visible:

```ofir
fn main() {
    println("\u{202E}")
}
```
