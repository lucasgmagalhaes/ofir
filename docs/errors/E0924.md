# E0924: a fetched package reaches outside its checkout

A package fetched from git or a registry is bounded by its checkout
(ADR 0092). Its `path` dependencies, its `build.root` and its
`build.native` files must resolve, after symbolic links, inside the
checkout, so that it cannot build files on the machine that nobody
named, locked or checksummed.

## Example

```jsonc
// ofir.json of the fetched package `text`
{
  "name": "text",
  "version": "1.0.0",
  "build": {"kind": "lib", "root": "src/index.of"},
  "dependencies": {
    "util": {"path": "../../../../work/util"},   // error[E0924]
  },
}
```

```text
error[E0924]: the dependency `util` is outside the checkout of a fetched package
 --> ofir.json:7:13
  = note: `/home/me/work/util` is not inside `/home/me/.ofir/git/checkouts/text-1f2e3d4c`
```

## Fix

The package must carry the files it builds: move them into its
repository, or depend on a published package instead of a directory. A
local package, a workspace member or an `overrides` entry of the root
has no bound.
