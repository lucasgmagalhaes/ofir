# E0919: a package cannot be published

`ofir publish` or `ofir yank` was refused (ADR 0079): the package's name
is not lowercase letters, digits and `-` starting with a letter, its
`version` is not `X.Y.Z`, it has no `license` (ADR 0081), a dependency
is a `path` or `git` one, the version is already in the index, or, for
`yank`, the version is not in it.

## Example

```jsonc
{
  "name": "greet",
  "version": "1.0.0",
  "dependencies": {"util": {"path": "../util"}}
}
```

A package in a registry can only depend on registry packages.

## Fix

Publish `util` first and depend on it by version (`"util": "^1"`). A
published version never changes: to fix one, publish a new version and
yank the old one with `ofir yank 1.0.0`.
