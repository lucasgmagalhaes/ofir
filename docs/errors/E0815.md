# E0815: compile-time code that needs the run time

Compile-time code is deterministic (spec 15.5). It cannot print, call an
`extern` function, or read a value that exists only at run time, such as
a local of the function around the `comptime` expression.

## Example

```ofir
fn greet() int {
    println("hello")
    return 1
}

fn main() {
    const n = comptime greet()
    println("{n}")
}
```

## Fix

Keep the I/O at run time and compute only the value at compile time:

```ofir
fn one() int {
    return 1
}

fn main() {
    const n = comptime one()
    println("hello {n}")
}
```
