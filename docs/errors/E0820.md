# E0820: atomic ordering not a constant

The memory ordering of an atomic intrinsic of `std.mem.atomic` is not a
constant `Ordering.X` (spec 14.4). The compiler turns each call into one
instruction, and the ordering is part of that instruction, so it must be
known where the program is compiled.

## Example

```ofir
import std.mem.atomic

let COUNT: int = 0

fn get(order: atomic.Ordering) int {
    unsafe {
        return atomic.atomicLoad(&mut COUNT as *mut int, order)
    }
}

fn main() {
    println("{get(atomic.Ordering.SeqCst)}")
}
```

## Fix

Write the ordering at the call, with a `match` when it varies:

```ofir
import std.mem.atomic

let COUNT: int = 0

fn get() int {
    unsafe {
        return atomic.atomicLoad(&mut COUNT as *mut int, atomic.Ordering.SeqCst)
    }
}

fn main() {
    println("{get()}")
}
```
