# E0346: a recursive type alias expands too many times

A type alias may name itself in a branch of a conditional type, and each
expansion is decided with its own arguments (spec 16.5). The recursion
must reach a branch that does not name the alias again: after 64 nested
expansions, the compiler stops with this error.

## Example

```ofir
type Grow<T> = if T is Option<infer U> { Grow<Option<T>> } else { T }

fn main() {
    const x: Grow<Option<int>> = 1
}
```

`Grow<Option<int>>` is `Grow<Option<Option<int>>>`, which is again an
`Option`, and so on without end.

## Fix

Make each step smaller, so that the condition ends up false:

```ofir
type Deep<T> = if T is Option<infer U> { Deep<U> } else { T }

fn main() {
    const x: Deep<Option<int>> = 1
}
```
