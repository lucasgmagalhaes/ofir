# E0206: invalid `@bench` function

`ofir bench` calls a `@bench` function with a `Bencher`, which the function
uses to time its code, and does not use its result: it takes one
parameter, `b: mut Bencher`, and returns nothing (spec 12.3).

## Example

```ofir
import std.testing.Bencher

fn sum(xs: [int]) int {
    let total = 0
    for x in xs {
        total += x
    }
    return total
}

@bench
fn benchSum() int {
    return sum([1, 2, 3])
}

fn main() {
}
```

## Fix

```ofir
import std.testing.Bencher

fn sum(xs: [int]) int {
    let total = 0
    for x in xs {
        total += x
    }
    return total
}

@bench
fn benchSum(b: mut Bencher) {
    b.run(() => {
        const _ = sum([1, 2, 3])
    })
}

fn main() {
}
```
