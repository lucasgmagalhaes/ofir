# E0917: a dependency is declared twice

A key of `devDependencies` is also a key of `dependencies` (ADR 0077). A
package has one source under each name, whatever the command.

```jsonc
{
  "name": "app",
  "dependencies": {"text": {"path": "deps/text"}},
  "devDependencies": {"text": {"path": "deps/text"}},   // error[E0917]
}
```

Keep it in `dependencies` if the program uses it, or in `devDependencies`
if only its tests do.
