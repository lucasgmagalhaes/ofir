# E0818: a `comptime` value that is not plain data

The value of a `comptime` expression is built into the program, so it must
be a number, `bool`, `str`, array, tuple, struct or enum of those (spec
15.5). Types that own memory on the heap, such as `List<T>` or `Map<K, V>`,
cannot be compile-time values.

## Example

```ofir
fn primes() List<int> {
    return [2, 3, 5, 7]
}

fn main() {
    const p = comptime primes()
    println("{p.len()}")
}
```

## Fix

Use a fixed-size array:

```ofir
fn primes() [int; 4] {
    return [2, 3, 5, 7]
}

fn main() {
    const p = comptime primes()
    println("{p[3]}")
}
```
