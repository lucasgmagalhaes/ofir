# E0822: thread-local global needs drop

A `@threadLocal` global has a type that is not Copy (spec 11.5). A thread
ends without dropping its globals, so a value that owns memory, such as a
`str` or a `List`, would leak at every thread exit.

## Example

```ofir
@threadLocal
let NAME: str = ""

fn main() {}
```

## Fix

Use a Copy type, such as a number, a `bool` or a raw pointer to memory
that the program frees itself:

```ofir
@threadLocal
let NAME: *u8 = 0 as *u8

fn main() {}
```
