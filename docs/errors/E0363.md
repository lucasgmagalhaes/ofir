# E0363: a `comptime if` condition is not known at compile time

The condition of a `comptime if` (spec 15.3) picks a branch while the
compiler expands each instance, so it must be known then. It is built from
`true`, `false`, constants, the `std.meta` predicates and comparisons of
`field.index` in a `comptime for`, with `!`, `&&` and `||`. A variable, a
call to an ordinary function or a comparison of run-time values is not.

## Example

```ofir
fn pick(fast: bool) int {
    comptime if fast {
        return 1
    }
    return 2
}

fn main() {
    const _ = pick(true)
}
```

## Fix

Use an ordinary `if` for a value known only at run time, or a constant for
one known at compile time:

```ofir
const FAST: bool = true

fn pick() int {
    comptime if FAST {
        return 1
    }
    return 2
}

fn main() {
    const _ = pick()
}
```
