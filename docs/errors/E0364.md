# E0364: `meta.fieldsOf` of a type that is not a struct

`comptime for field in meta.fieldsOf<T>()` (spec 15.3) expands its body
once per field of `T`, so `T` must be a struct. A type parameter must be
narrowed to one first, with `comptime if meta.isStruct<T>()`; a concrete
type that is not a struct has no fields to list.

## Example

```ofir
import std.meta

fn count<T>(value: &T) int {
    let n = 0
    comptime for _field in meta.fieldsOf<T>() {
        n += 1
    }
    return n
}

fn main() {
    const _ = count(&1)
}
```

## Fix

Narrow `T` to a struct, and handle other types in the `else` branch:

```ofir
import std.meta

fn count<T>(value: &T) int {
    let n = 0
    comptime if meta.isStruct<T>() {
        comptime for _field in meta.fieldsOf<T>() {
            n += 1
        }
    }
    return n
}

fn main() {
    const _ = count(&1)
}
```
