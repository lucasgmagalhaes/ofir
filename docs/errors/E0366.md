# E0366: an array length out of range

An array length expression (spec 8.7) is evaluated exactly: every
operation must give a value from 0 to 4294967295, and `/` and `%` need a
divisor other than 0. A length without parameters is checked where it is
written; one with const parameters, at each instantiation.

## Example

```ofir
fn shorter<const N: int>(xs: [int; N]) [int; N - 1] {
    return [xs[0]; N - 1]
}

fn main() {
    const xs: [int; 0] = []
    println("{shorter(xs).len()}")
}
```

`N - 1` with `N = 0` is -1.

## Fix

Instantiate with arguments for which the length is in range, or write a
length that cannot fail, such as `N + 1`.
