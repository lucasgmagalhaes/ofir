# E0921: a source is not trusted

The root manifest has `trust` (ADR 0081), and a dependency anywhere in
the graph comes from a source it does not list: a registry whose index
is not in `trust.registries`, or a git repository whose URL starts with
no entry of `trust.git`. It is reported before the source is fetched.
Path dependencies and overrides are always trusted; a dependency's own
`trust` is not read, and in a workspace the root's applies.

## Example

```jsonc
{
  "dependencies": {"shade": {"git": "https://example.com/shade", "rev": "main"}},
  "trust": {"git": ["https://github.com/acme/"]}
}
```

```text
error[E0921]: `shade` comes from `https://example.com/shade`, which no entry of `trust.git` starts
```

## Fix

Depend on a package from a trusted source instead, or, if the source
is one the project accepts, add it: its index to `trust.registries`, or
a prefix of its URL to `trust.git`.
