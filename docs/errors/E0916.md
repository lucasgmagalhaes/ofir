# E0916: a cycle of dependencies

The packages of a program form a graph without cycles (ADR 0076): a
package cannot depend, directly or through others, on a package that
depends on it. The error is at the dependency that closes the cycle, and
its note names the packages of the cycle in order.

## Example

`deps/a/ofir.json`:

```jsonc
{
  "name": "a",
  "build": {"kind": "lib", "root": "src/index.of"},
  "dependencies": {"b": {"path": "../b"}}
}
```

`deps/b/ofir.json`:

```jsonc
{
  "name": "b",
  "build": {"kind": "lib", "root": "src/index.of"},
  "dependencies": {"a": {"path": "../a"}}
}
```

## Fix

Move what both packages need to a third package that neither depends on,
or merge the two packages into one.
