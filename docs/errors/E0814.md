# E0814: `comptime panic` reached by an instance

`comptime panic("message")` (spec 15.3) marks a branch that no instance
should keep. Expanding a generic function for a type whose `comptime if`
keeps that branch is a compile error, reported at the call that created
the instance, with the given message.

## Example

```ofir
import std.meta

fn double<T: Copy>(x: T) T {
    comptime if meta.isInteger<T>() {
        return x * 2
    } else {
        comptime panic("double: {meta.nameOf<T>()} is not an integer")
    }
}

fn main() {
    const _ = double(true)
}
```

## Fix

Call the function with a type it supports, or add a branch for the type:

```ofir
import std.meta

fn double<T: Copy>(x: T) T {
    comptime if meta.isInteger<T>() {
        return x * 2
    } else {
        comptime panic("double: {meta.nameOf<T>()} is not an integer")
    }
}

fn main() {
    const _ = double(21)
}
```
