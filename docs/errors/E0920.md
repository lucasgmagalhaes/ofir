# E0920: a locked package has an advisory

`ofir audit` found an advisory of the registry (ADR 0081) that affects
the version of a package in `ofir.lock`. The index's
`advisories/<package file>` lists them, one JSON line each, with the
`versions` they affect; a `withdrawn` one is not reported. The exit
status is 1.

## Example

```text
error[E0920]: `greet` 1.0.0 is affected by OFIR-2026-0001 (high): ...; fixed in 1.1.0
```

## Fix

Move to a version that fixes it: raise the requirement if it excludes
that version (`"greet": "^1.1"`) and run `ofir update greet`. If the
advisory does not apply to the project, accept it in the root manifest,
which turns the error into a note:

```jsonc
{
  "audit": {"ignore": ["OFIR-2026-0001"]}
}
```
