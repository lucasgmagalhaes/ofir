# E0008: invalid UTF-8

A source file must be UTF-8 (spec 1.1): every byte above `0x7F` must be
part of a well-formed UTF-8 character. Overlong forms, surrogates
(U+D800 to U+DFFF) and values above U+10FFFF are invalid too. The check
covers the whole file, comments and string literals included, so that
every `str` literal is valid UTF-8. Each invalid sequence is reported
once, at its first byte.

A file saved in Latin-1 or Windows-1252 is the usual cause.

## Example

A file whose bytes are, in Latin-1, `println("café")`: the `é` is the
single byte `0xE9`.

```text
println("caf\xE9")
```

## Fix

Save the file as UTF-8, or write the character as an escape. Bytes that
are not text belong in a byte string, `b"\xe9"`.

```ofir
fn main() {
    println("caf\u{E9}")
}
```
