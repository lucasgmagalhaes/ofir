# E0817: `comptime fn` called at run time

A `comptime fn` can only run at compile time (spec 15.1): it may be called
from a `comptime` expression or from another `comptime fn`, not from code
that runs at run time.

## Example

```ofir
comptime fn square(x: int) int {
    return x * x
}

fn main() {
    const n = square(3)
    println("{n}")
}
```

## Fix

Call it inside a `comptime` expression:

```ofir
comptime fn square(x: int) int {
    return x * x
}

fn main() {
    const n = comptime square(3)
    println("{n}")
}
```
