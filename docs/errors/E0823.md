# E0823: not a C function

A value of a C function pointer type, `extern "C" fn(A) R`, must be the
name of an `extern "C"` function (spec 11.3). A closure or an Ofir
function uses the internal calling convention and may need an
environment, which C cannot pass.

## Example

```ofir
extern "C" {
    fn atexit(f: extern "C" fn()) i32
}

fn done() {}

fn main() {
    unsafe { atexit(done) }
}
```

## Fix

Declare the function `extern "C"`; its state, if any, goes through a
global or the library's user-data pointer:

```ofir
extern "C" {
    fn atexit(f: extern "C" fn()) i32
}

extern "C" fn done() {}

fn main() {
    unsafe { atexit(done) }
}
```
