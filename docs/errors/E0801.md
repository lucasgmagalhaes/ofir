# E0801: constant uses a non-constant

A constant's value is computed by the compiler, so it may use only
literals, other constants and operators. A function call, a variable or
a method call has no value at compile time.

A constant computed by `comptime` code (spec 15.1) gets its value only
after type checking, so it cannot be used in another constant or as an
array length either.

## Example

```ofir
fn limit() int {
    return 10
}

const MAX = limit() * 2

fn main() {
    println("{MAX}")
}
```

## Fix

Write the value with constants, or compute it at run time with `const`:

```ofir
const LIMIT = 10
const MAX = LIMIT * 2

fn main() {
    println("{MAX}")
}
```

Or run the function at compile time with `comptime` (stage 1):

```ofir
fn limit() int {
    return 10
}

const MAX: int = comptime (limit() * 2)

fn main() {
    println("{MAX}")
}
```
