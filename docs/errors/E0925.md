# E0925: a URL holds a credential

A git URL in `ofir.json`, or `OFIR_REGISTRY`, has a password
(`user:secret@host`), or is an `http` or `https` URL with a user part,
which is how a token is usually given. The URL would be written into
`ofir.lock`, which is committed, and shown in diagnostics, so the
compiler rejects it before fetching anything (ADR 0092).

## Example

```jsonc
// ofir.json
{
  "name": "app",
  "dependencies": {
    "text": {"git": "https://bot:ghp_secret@example.com/text", "version": "^1"},   // error[E0925]
  },
}
```

```text
error[E0925]: the git URL of `text` holds a credential
 --> ofir.json:4:21
  = help: remove it from the URL and let git supply it: a credential helper or an SSH key
```

## Fix

Write the URL without the credential, `https://example.com/text`, and
give the credential to git, which the compiler runs to fetch:
`git config --global credential.helper store`, a `GIT_ASKPASS`
program, or an SSH URL (`git@example.com:text`, `ssh://git@example.com/text`),
whose user part is not a secret.
