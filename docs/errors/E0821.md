# E0821: ordering not allowed

An atomic intrinsic of `std.mem.atomic` is given an ordering it does not
allow (spec 14.4): a load cannot release, a store cannot acquire, and a
fence cannot be `Relaxed`. A load takes `Relaxed`, `Acquire` or `SeqCst`;
a store takes `Relaxed`, `Release` or `SeqCst`.

## Example

```ofir
import std.mem.atomic

let READY: bool = false

fn main() {
    unsafe {
        atomic.atomicStore(&mut READY as *mut bool, true, atomic.Ordering.Acquire)
    }
}
```

## Fix

Use the ordering the operation allows, here `Release`:

```ofir
import std.mem.atomic

let READY: bool = false

fn main() {
    unsafe {
        atomic.atomicStore(&mut READY as *mut bool, true, atomic.Ordering.Release)
    }
}
```
