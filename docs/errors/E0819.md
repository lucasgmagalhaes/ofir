# E0819: reserved C symbol

An `extern "C"` function outside `std` defines `main` or a symbol that
starts with `ofir_`, through `@export("name")` or its own name. These
symbols belong to the runtime and the generated code (spec 11.4): the
runtime's `main` calls the program's `main`, so a second `main` would
replace the entry point and the program would not run.

## Example

```ofir
@export("main")
extern "C" fn start() i32 {
    return 0
}

fn main() {
}
```

## Fix

Give the function a symbol of its own, with a prefix for your library:

```ofir
@export("calc_start")
extern "C" fn start() i32 {
    return 0
}

fn main() {
}
```
