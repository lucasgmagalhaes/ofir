# E0923: the project needs another toolchain

The root manifest's `toolchain` is a range of compiler versions
(ADR 0082), and the compiler that runs is not in it. The project is
built with another version of Ofir, whose language, standard library or
diagnostics may differ, so the compiler stops before reading the
dependencies.

## Example

```jsonc
// ofir.json
{"name": "app", "version": "0.1.0", "toolchain": ">=0.6.0"}
```

```text
error[E0923]: this project needs the toolchain `>=0.6.0`, not 0.5.0
 --> ofir.json:1:50
  = help: switch to an installed version: `sh ~/.ofir/install.sh --use 0.6.2`
```

## Fix

Switch to a version in the range, installing it first if the help line
names none:

```text
sh ~/.ofir/install.sh ofir-0.6.2-x86_64-linux-gnu.tar.gz
sh ~/.ofir/install.sh --use 0.6.2
```

Or, when the project builds with this version, widen the range in
`ofir.json`.
