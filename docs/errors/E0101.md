# E0101: nesting too deep

The source nests more than 256 levels deep (spec A.8). Each level of a
nested expression, block, type or pattern counts, and so does each step
of a chain: an operator, an `as`, a call, a field access or an `else if`.
The parser reports the error once, at the token where the limit is
passed, and stops: the rest of the file is not checked.

The limit keeps every phase of the compiler within a bounded stack, so
that malformed or generated input fails with a diagnostic instead of a
crash. Real code is far from it.

## Example

A chain of 300 additions, `0 + 1 + 1 + ... + 1`, reports E0101 at the
257th operand.

## Fix

Split the expression with intermediate bindings, or use a loop:

```ofir
fn main() {
    let total = 0
    for _ in 0..300 {
        total += 1
    }
    println("{total}")
}
```
