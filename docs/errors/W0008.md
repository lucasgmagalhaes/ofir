# W0008: suspicious code

The code is valid but almost certainly not what was meant (ADR 0071):

- a place is compared with itself, as `x == x`: the result is always the
  same;
- a place is assigned to itself, as `x = x`: nothing changes.

A place is a local, `self`, or a field of one. Floating-point
comparisons are not reported, since `x != x` tests for NaN. Silence it
with `@allow(suspicious)`, or with `"lints": {"suspicious": "allow"}` in
`ofir.json`.

## Example

```ofir
fn larger(a: int, b: int) bool {
    return a > a
}

fn main() {
    println("{larger(2, 1)}")
}
```

## Fix

Compare the values that were meant:

```ofir
fn larger(a: int, b: int) bool {
    return a > b
}

fn main() {
    println("{larger(2, 1)}")
}
```
