# E0502: the pattern after `name @` binds names

`name @ pattern` binds the whole value to `name` once `pattern` matches.
The pattern after the `@` only tests the value: it may not bind names of
its own, since the same value would then be bound twice. Use `_` in the
inner pattern and read the parts through `name`, or bind the parts without
`@`.

## Example

```ofir
fn show(o: Option<int>) {
    match o {
        whole @ Option.Some(n) => println("{n}")
        Option.None => println("none")
    }
}

fn main() {
    show(Option.Some(2))
}
```

## Fix

```ofir
fn show(o: Option<int>) {
    match o {
        Option.Some(n) => println("{n}")
        Option.None => println("none")
    }
}

fn main() {
    show(Option.Some(2))
}
```
