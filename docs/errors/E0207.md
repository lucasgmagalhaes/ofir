# E0207: ambiguous name from glob imports

Two glob imports (`import path.*`) bring the same name for different
declarations, and the module uses it (spec 7.2). The name binds to
neither: import the one you mean by name, which takes precedence over
both globs, or qualify it with its module.

## Example

```ofir
import std.path.*
import std.strings.*

fn main() {
    println(join(["a", "b"], ", "))
}
```

## Fix

```ofir
import std.path.*
import std.strings.*
import std.strings.join

fn main() {
    println(join(["a", "b"], ", "))
}
```
