# E0329: conflicting default methods

Two interfaces give a default for the same method, and an interface
embedding both, a type asserting both or a type parameter bounded by both
would have to pick one (spec 9.3).

## Example

```ofir
interface Named {
    fn name(self) str

    fn hello(self) str {
        return "hi {self.name()}"
    }
}

interface Greeter {
    fn name(self) str

    fn hello(self) str {
        return "hello {self.name()}"
    }
}

struct Robot: Named + Greeter {
    fn name(self) str {
        return "r2"
    }
}

fn main() {
    println(Robot{}.hello())
}
```

## Fix

Declare the method in the type (or the interface) that has both:

```ofir
interface Named {
    fn name(self) str

    fn hello(self) str {
        return "hi {self.name()}"
    }
}

interface Greeter {
    fn name(self) str

    fn hello(self) str {
        return "hello {self.name()}"
    }
}

struct Robot: Named + Greeter {
    fn name(self) str {
        return "r2"
    }

    fn hello(self) str {
        return "beep {self.name()}"
    }
}

fn main() {
    println(Robot{}.hello())
}
```
