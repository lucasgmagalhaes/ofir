# E0205: invalid `@test` function

A `@test` function is called by the test runner with no arguments, and
its result is not used: it takes no parameters and returns nothing. A
test fails by panicking, as an `assert` does.

## Example

```ofir
import std.testing.assert

@test
fn adds(n: int) {
    assert(n + 1 == 2)
}

fn main() {
}
```

## Fix

```ofir
import std.testing.assert

@test
fn adds() {
    const n = 1
    assert(n + 1 == 2)
}

fn main() {
}
```
