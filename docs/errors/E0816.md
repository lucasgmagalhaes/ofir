# E0816: compile-time evaluation failed

A `comptime` expression is run by the compiler. If it panics, overflows,
divides by zero, indexes out of bounds, nests calls too deep or runs out
of its step budget (10 million steps by default, spec 15.5), the build
fails with this error. When the failure is inside a called function, notes
give the function and the line where it failed, then the calls that led
there, innermost first.

## Example

```ofir
fn add(x: u8, y: u8) u8 {
    return x + y
}

fn main() {
    const n = comptime add(200, 100)
    println("{n}")
}
```

## Fix

Fix the computation, or give a slow but correct one more steps with
`@comptimeBudget(n)` on the enclosing declaration:

```ofir
fn add(x: u8, y: u8) u8 {
    return x.wrappingAdd(y)
}

fn main() {
    const n = comptime add(200, 100)
    println("{n}")
}
```
