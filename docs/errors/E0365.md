# E0365: `dyn any`

`any` (spec 9.8, ADR 0039) is a `dyn` type already: `v: any` borrows a
value of any type and `Box<any>` owns one. `dyn` in front of it is
redundant and rejected.

## Example

```ofir
fn describe(v: dyn any) str {
    return v.typeName()
}

fn main() {
    println(describe(&1))
}
```

## Fix

Write `any` alone:

```ofir
fn describe(v: any) str {
    return v.typeName()
}

fn main() {
    println(describe(&1))
}
```
