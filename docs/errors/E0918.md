# E0918: invalid build configuration

The profile chosen with `--profile` does not exist, an entry of the
manifest's `profiles` has an unknown key or a bad value, or a file of
`build.native` cannot be found (ADR 0078).

## Example

```jsonc
{
  "name": "app",
  "profiles": {"fast": {"inherits": "release", "opt": 4}}
}
```

`opt` must be 0, 1, 2 or 3.

## Fix

Use a profile that is built in (`dev`, `release`) or named in `profiles`,
give `inherits` as `"dev"` or `"release"`, `opt` from 0 to 3 and
`debugInfo` as `true` or `false`, and list native files that exist,
relative to the manifest.
